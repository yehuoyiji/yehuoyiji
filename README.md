## 代表开源项目：鲁大魔视角 Agent Skill（`ludamo-perspective`）

👉 **项目仓库**：[`yehuoyiji/ludamo-perspective`](https://github.com/yehuoyiji/ludamo-perspective)  
👉 **开源协议**：`CC BY-NC-SA 4.0`（**永久免费开源 · 严禁倒卖或商业捆绑**）

### 我为什么做这个项目
刷过很多创业、电商、管理和职场类的直播切片，干货很多，但碎片化太严重——真遇到具体业务卡点时，根本记不清哪场讲过什么，普通 AI 回答又容易泛泛而谈甚至编造名言。

于是我自己写了一套自动化采集与蒸馏管道，从 **1,500+ 条公开视频**里逐条转写、交叉去重、剔除连麦干扰和误归类，最后做成了这个开源 Skill：
- 沉淀 **29 条可执行判断规则** 与 **28 个精选核对案例**（附真实适用条件与改判边界）；
- 把 **1,449 条去重后的独立视频证据** 按 11 个主题拆分成轻量化分卷，每条保留**精确时间戳与原片链接**；
- 内置**零第三方依赖的 Python 检索脚本**，支持直接装进 Antigravity、Claude Code、Codex、Cursor，也能当独立本地资料库查。

做完之后我决定**直接免费开源**——一方面希望把真正有用的工具留在公开社区，另一方面也特别反感有人把社区整理的东西拿去挂闲鱼、塞付费群割信息差韭菜，所以项目明确采用非商用协议并长期持续迭代。
